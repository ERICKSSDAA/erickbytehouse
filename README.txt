BYTE HOUSE - Proyecto web
==========================
Tienda tecnológica creada en HTML, CSS y JavaScript.

Archivos:
- index.html
- css/style.css
- js/app.js

Incluye:
- Catálogo de celulares, parlantes, monitores, laptops, gaming y accesorios.
- Imágenes externas por URL.
- Filtros por categoría.
- Carrito funcional de demostración.
- Cambio simple PEN/USD.
- Diseño responsive para PC, tablet y celular.

Uso:
1. Descomprime el ZIP.
2. Abre index.html en Chrome/Edge.
3. Necesitas conexión a Internet para cargar las imágenes por URL.
